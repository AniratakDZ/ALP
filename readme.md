# ALP (Aniratak's learning project)

I created this project to learn more about Paper/Spigot development. 
To that end, I worked with a few friends to come up with 50 features that I plan to implement over the long term.

Each feature should be managed via permissions and can also be enabled or disabled via a GUI.

## ✨ Planned Features
### Gameplay
1. [ ] Lucky Blocks (Random events during block mining)
2. [ ] TNT Punch (Every punch spawns TNT)
3. [ ] Random Teleport Stick (Right-clicking teleports to a random location)
4. [ ] Low Gravity (Players jump higher)
5. [ ] Double Jump (Player can jump a second time in mid-air)
6. [ ] Fire Feet (While running, fire spawns under players)
7. [ ] Lighting Sword (Hits summon lightning strikes)
8. [ ] Explosive Arrows (Arrows explode on impact)
9. [ ] Dash Item (Right-clicking gives you a forward boost)
10. [ ] Random Drops (Every block mined drops a totally random item)

### Survival
1. [ ] Death Chest (Items are placed in a chest upon death)
2. [ ] Auto Smelt (Ores are smelted immediately)
3. [ ] Tree Feller (Fells a tree immediately)
4. [ ] Backpack (Additional inventory slots)
5. [ ] Portable Crafting Table (Item opens the crafting interface)
6. [ ] Portable Furnace (Mobile furnace)
7. [ ] Silk Spawner (Mob Spawner will drop, if mined with silk-touch)
8. [ ] Crop Replant (Automatically replants fields)
9. [ ] Infinite Water Bucket (Special bucket with infinite water inside)
10. [ ] Vein Miner (Mines an entire ore vein)

### Mobs
1. [ ] Fast Zombies (Zombies can sprint)
2. [ ] Giant Chickens (Chickens can be huge!)
3. [ ] Random Mob Size (Mobs got random size on spawn)
4. [ ] Boss Zombie (Super-strong zombie with a boss bar)
5. [ ] Mob Splitter (Mob splits into tinier versions upon death)
6. [ ] Invisible Creeper (New creeper that can be invisible)
7. [ ] Friendly Skeletons (Skeletons attack other mobs)
8. [ ] Exploding Chickens (Chickens can explode on death)
9. [ ] Pet System (Simple pet follows the player)
10. [ ] Mob Arena Event (Arena with wave system)

### Commands
1. [ ] /hat (Put item in hand on your head)
2. [ ] /feed (Refill hunger)
3. [ ] /heal (Refill health)
4. [ ] /speed (Toggle speed)
5. [ ] /randomtp (Random teleports player)
6. [ ] /nickcolor (Change chat name color)
7. [ ] /sit (Sit down)
8. [ ] /shrug (Funny chat messages)
9. [ ] /spin (Player spins around, like a record baby)
10. [ ] /launch (Launch player into the air) 

### GUI
1. [ ] Daily Rewards (Daily rewards with tasks to complete)
2. [ ] Shop GUI (Trading GUI)
3. [ ] Warp GUI (Possibility to set warps and teleport)
4. [ ] Player Menu (Clickable player information)
5. [ ] Cosmetic Menu (Select particles)
6. [ ] Vote Reward GUI (Claim rewards for voting)
7. [ ] Trash GUI (Mobile trash can)
8. [ ] Settings GUI (Toggle for features)
9. [ ] Random Reward Crate (Small loot box)
10. [ ] Mini Casino GUI (Con flip, slots etc.)

## 🛠 Tech Stack
- Java
- Paper API

learn as much as possible about Bukkit or Paper/Spigot and have fun doing it.
